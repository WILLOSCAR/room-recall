# ADRs

Use this directory for durable decisions about RoomRecall.

Create an ADR when a decision changes one of these areas:

- Product scope or MVP boundary
- Place Graph and item data model
- AR, 3D, LiDAR, or scan strategy
- Privacy and storage of home photos or room scans
- Agent behavior for uncertainty, merging, or intent expansion

Suggested filename format:

```text
0001-short-decision-title.md
```
