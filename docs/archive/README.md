# Archive

Superseded documents, kept for provenance only.

**Nothing in this directory is current.** It is not a build contract, not a glossary, not a workflow, and not a live decision. If an archived document disagrees with `CONTEXT.md`, `docs/adr/`, `docs/nestory-v1-prd.md`, or a live `.scratch/<effort>/` ticket, the live document wins — always, and without discussion.

Archived files may reference paths and process vocabulary that no longer exist. That is expected: they are frozen records of what was true when written. Do not "fix" them, and do not follow their instructions.

`.scratch/` holds only live issue-tracker and wayfinder state. When a document is retired it moves here rather than staying in `.scratch/` or `docs/`.
