Type: research
Status: open

## Question

For browser or phone RGB capture of one rented room, which current production-compatible pipeline can reliably return a room envelope, scale confidence, and 5-10 large Furniture proposals without requiring LiDAR, and what must remain an explicit failure or manual fallback?

The answer must compare primary-source evidence, licenses, compute/runtime constraints, input guidance, output contract, confidence signals, and a smallest reproducible spike. It must distinguish geometry reconstruction from object/furniture proposal generation.
