# 04 — Prototype Mobile Capture And Coverage Guidance

Type: prototype
Status: open
Blocked by: 02 — Define The Five-Minute Activation Path; 03 — Select The Bounded Visual Reconstruction Route

## Question

Which mobile capture interaction gives a first-time user enough guidance to produce usable RGB evidence, scale evidence, and coverage without making the session feel like operating a surveying tool?

The prototype should make capture readiness, progress, missed coverage, blur, scale-anchor quality, upload state, cancellation, and retry concrete enough for a human to judge.
