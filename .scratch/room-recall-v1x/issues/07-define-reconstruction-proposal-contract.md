# 07 — Define The Reconstruction Job And Proposal Contract

Type: grilling
Status: open
Blocked by: 04 — Select The Bounded Visual Reconstruction Route; 06 — Set The Sensitive Evidence Boundary

## Question

What stable public contract should connect a Scan Session to an asynchronous reconstruction job and then to typed Vision Scan Proposals without allowing raw model output to become Place Graph truth?

Resolve job states, coordinate and scale evidence, Geometry Records, Furniture candidate identity, confidence, partial success, privacy holds, retry/idempotency, proposal diff, and the minimum evidence retained for explanation and undo. Candidate identity must resolve through match, create, merge, reject, or needs-more-evidence decisions; an unknown Place Reference must never be replaced by an arbitrary Container.
